# TGB Law website starter

A responsive, multi-page static website for TGB Law, prepared for GitHub Pages.

## Included pages
- `index.html` — Home
- `about.html` — About the practice
- `services.html` — Legal services
- `insights.html` — Legal Insights landing page
- `contact.html` — Contact details (placeholders to complete)
- `privacy.html` — Draft privacy notice (must be reviewed)

## Before publishing
1. Confirm the supplied email, telephone number and office address in `contact.html`.
2. Confirm the professional biography, qualifications, service descriptions and office details.
3. Review all copy for compliance with the applicable professional conduct and publicity rules in Trinidad and Tobago.
4. Have the privacy notice reviewed and amended to reflect the practice's actual data-handling arrangements.
5. Confirm the Facebook and LinkedIn links and professional headshot on the website.

## Preview locally
Open `index.html` in a web browser. The site uses Google Fonts; if offline, fallback fonts will display.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `tgb-law-website`.
2. Upload the contents of this folder (not the outer folder itself) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. GitHub will provide a `https://YOUR-USERNAME.github.io/tgb-law-website/` address.

## Connect www.tgblawtt.com
After the GitHub Pages site is working, add `www.tgblawtt.com` under **Settings → Pages → Custom domain**. Then update DNS records at the domain registrar exactly as GitHub Pages instructs. Do not change existing DNS records until you know which services (such as email) depend on them. Enable Enforce HTTPS once it becomes available.

This is a static website. It does not contain a working enquiry form, client portal, booking system, or database. The contact details are intentionally placeholders pending confirmation.
